# Trip Itinerary

A one-page app for planning a trip together. Add ideas (with an optional date and a note), vote Yes / Maybe / No, see who voted what, and comment. Updates live for everyone.

- Hosted on GitHub Pages from `index.html` on `main`.
- Data lives in the Supabase project `itinerary-voting`. The key in `index.html` is the public (publishable) key; access is controlled by row-level security, which is open to anyone with the link.
